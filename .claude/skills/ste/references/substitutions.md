# Word substitutions

The left column has words and phrases that ASD-STE100 does not approve. The right column
has what to write in their place. The list holds the words that occur most in software and
robotics work. It is not the full ASD Dictionary. See the copyright note in
[SKILL.md](../SKILL.md).

If a word is not in this table, apply the test: is the word short, common, and does it have
one meaning here? If yes, use it. If no, find a simpler word.

## Quantity and vagueness

| Not approved | Use |
| --- | --- |
| a number of, several, various | the exact number, or "some" |
| the majority of | most |
| a portion of | part of, or the exact part |
| approximately | about |
| sufficient | enough |
| numerous, multiple | many, or the exact number |
| minimal | small, or the exact value |
| excessive | too much, or the exact limit |
| etc., and so on | give the full list |
| significant | large, important, or the exact value |

## Modals and hedges

| Not approved | Use |
| --- | --- |
| is able to, has the ability to | can |
| is required to, is obliged to | must |
| should be able to | can, or say what is not sure |
| it is recommended that | I recommend that, or use the imperative |
| it is possible that | can, may |
| it is important to note that | remove it |
| as you can see | remove it |

# Noun clusters

Do not put more than 3 nouns together. Break the cluster with "of", "for", "in", or "that".
Read the cluster from right to left to find the true subject.

| Too long | Break it up |
| --- | --- |
| joint position feedback signal limit | the limit of the joint position signal |
| policy observation space vector size | the size of the observation vector |
| training run reward weight table | the table of reward weights for the run |
| servo pushrod ball joint clearance | the clearance of the ball joint on the pushrod |
| pot calibration file format check | the check of the format of the calibration file |
| dashboard summary page reward note | the reward note on the summary page |
| queue runner heartbeat write interval | the interval between the heartbeat writes of the runner |

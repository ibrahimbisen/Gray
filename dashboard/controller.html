Deadzone, both sticks

Saved to Playground\settings.json the moment you pick something. Takes effect the next time pilot.bat runs. Not while the tkinter settings window is open — it writes the same file when it closes, so whichever goes last wins.

SL and SR are left off on purpose: they only exist when a Joy-Con is detached, and this is one piece.

Probe it means run Playground\pad.bat, press the control, and read the number it prints. Buttons 0–7 were measured that way on a PowerA Switch pad; the rest have never been pressed on this machine, so this page does not guess them.

Speeds are sticky: a press changes the speed and it stays there, like a throttle. The window only reports keys going down, never coming up, so hold-to-walk cannot be written against it.

Not the letter keys. MuJoCo binds every letter A–Z to one of its own view toggles inside its C++ window, before Python sees the key — WASD steered the robot and scrambled the picture at the same time. The numpad is the one block it leaves alone.

The map on this page is Playground\settings.json, read live — not a copy. The numpad steps come from Playground\control.py and the trained ranges from gray\tasks\walk_env_cfg.py; those two are still copied here, so change them and change this page in the same edit.
